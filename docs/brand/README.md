# Swoop brand (v3, quiet wordmark)

| File | Use |
| --- | --- |
| `swoop-logo-light.svg` / `swoop-logo-dark.svg` | The logo: the word `swoop` alone, ink on light / white on the sky or dark backgrounds |
| `swoop-logo-mono-black.svg` / `swoop-logo-mono-white.svg` | One-colour wordmark |
| `swoop-symbol.svg`, `swoop-symbol-512.png`, `swoop-symbol-mono-black.svg` | The app icon artwork: a white serif s on the dusk sky (for avatars and small places where the word won't fit) |
| `swoop-shield-logo-light.svg` / `-dark.svg`, `swoop-shield.svg` | Swoop Shield lockup (`swoop` + italic `shield`) and Shield mark (white serif s on a sea-sage shield; Shield only) |
| `palette.css` | Colours, gradients, card/glass tokens and font stacks as CSS custom properties |

**Look:** soft, blurred dusk-sky backgrounds (slate blue, periwinkle, mauve, dusty rose, peach) with fine grain;
white rounded cards; frosted-glass pill buttons; lots of space. No saturated fills.

**Colours:** Dusk `#4A5A82` (primary), Slate `#5F7393`, Periwinkle `#9AA5CC`, Mauve `#9C8A9E`, Rose `#D29B9E`, Peach `#E8A986`,
Cream `#F6F3EE`, Ink `#1E1C21`, Night `#262A3B`.
Cleaner/Shield signals: Freed `#86AD95`, Review `#D8AC6C`, Danger `#C8776D`, Shield (sea sage) `#6FA59C` (use the darker text shades in `palette.css` for text on light).

**Logo:** lowercase `swoop` in Fraunces Light (wght 330, opsz 72, SOFT 100, WONK 0, tracking −1%), no symbol beside it. App icon: a white serif lowercase s (Fraunces Regular) on the dusk-sky squircle.

**Type:** Fraunces (wordmark and headlines; opsz 72, SOFT 100, WONK 0; italic for one accent word), Inter (text), JetBrains Mono (shortcuts and numbers). All SIL Open Font License 1.1.

**Rules of thumb:** lowercase `swoop` in the logo, "Swoop" in running text. Don't stretch, rotate, outline or recolour the logo. Keep clear space of the x-height of the wordmark on every side. White text only on the deeper parts of the sky. Calm, specific, honest copy: no scare tactics, no "Pro".

App icon sources: `Resources/AppIcon.iconset`, `Resources/AppIcon.icns`. Menu-bar templates: `Resources/MenuBar`. DMG art: `Resources/DMG`.
