# Swoop brand (v2)

| File | Use |
| --- | --- |
| `swoop-logo-light.svg` / `swoop-logo-dark.svg` | Main lockup on light / on the sky or dark backgrounds |
| `swoop-logo-mono-black.svg` / `swoop-logo-mono-white.svg` | One-colour lockup |
| `swoop-symbol.svg`, `swoop-symbol-512.png`, `swoop-symbol-mono-black.svg` | The symbol on its own (frosted keycap + swoop on a dusk sky) |
| `swoop-shield-logo-light.svg` / `-dark.svg`, `swoop-shield.svg` | Swoop Shield lockup and sub-mark (Shield only) |
| `palette.css` | Colours, gradients, card/glass tokens and font stacks as CSS custom properties |

**Look:** soft, blurred dusk-sky backgrounds (slate blue, periwinkle, mauve, dusty rose, peach) with fine grain;
white rounded cards; frosted-glass pill buttons; lots of space. No saturated fills.

**Colours:** Dusk `#4A5A82` (primary), Slate `#5F7393`, Periwinkle `#9AA5CC`, Mauve `#9C8A9E`, Rose `#D29B9E`, Peach `#E8A986`,
Cream `#F6F3EE`, Ink `#1E1C21`, Night `#262A3B`.
Cleaner/Shield signals: Freed `#86AD95`, Review `#D8AC6C`, Danger `#C8776D`, Shield (sea sage) `#6FA59C` (use the darker text shades in `palette.css` for text on light).

**Type:** Fraunces (lowercase wordmark and headlines; opsz 72, SOFT 100, WONK 0; italic for one accent word), Inter (text), JetBrains Mono (shortcuts and numbers). All SIL Open Font License 1.1.

**Rules of thumb:** lowercase `swoop` in the logo, "Swoop" in running text. Don't stretch, rotate, outline or recolour the logo. Keep clear space of half the symbol height. White text only on the deeper parts of the sky. Calm, specific, honest copy: no scare tactics, no "Pro".

App icon sources: `Resources/AppIcon.iconset`, `Resources/AppIcon.icns`. Menu-bar templates: `Resources/MenuBar`. DMG art: `Resources/DMG`.
