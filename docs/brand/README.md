# Swoop brand

| File | Use |
| --- | --- |
| `swoop-logo-light.svg` / `swoop-logo-dark.svg` | Main lockup on light / dark backgrounds |
| `swoop-logo-mono-black.svg` / `swoop-logo-mono-white.svg` | One-colour lockup |
| `swoop-symbol.svg`, `swoop-symbol-512.png`, `swoop-symbol-mono-black.svg` | The symbol on its own (keycap + swoop) |
| `swoop-shield-logo-light.svg` / `-dark.svg`, `swoop-shield.svg` | Swoop Shield lockup and sub-mark (Shield only) |
| `palette.css` | Colours, gradients and font stacks as CSS custom properties |

**Colours:** Iris `#5B4CFF` (primary), Night Ink `#0D0B1E`, Indigo `#1E1B5E`, Orchid `#B35CF0`, Apricot `#FF9A76`, Paper `#FAF8F5`.
Cleaner/Shield signals: Freed `#1FA971`, Review `#E8930C`, Danger `#E5484D`, Shield `#12A594` (use the darker text shades in `palette.css` for text on light).

**Type:** Inter Display / Inter (headlines, text), Instrument Serif *italic* (one accent word per headline), JetBrains Mono (shortcuts and numbers). All SIL Open Font License 1.1.

**Rules of thumb:** lowercase `swoop` in the logo, "Swoop" in running text. Don't stretch, rotate, outline or recolour the logo. Keep clear space of half the symbol height. Calm, specific, honest copy: no scare tactics, no "Pro".

App icon sources: `Resources/AppIcon.iconset`, `Resources/AppIcon.icns`. Menu-bar templates: `Resources/MenuBar`. DMG art: `Resources/DMG`.
